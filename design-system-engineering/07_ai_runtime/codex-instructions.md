# Codex Instructions

Before UI or design-system changes, read `ai-readable-index.json` in order and consume the current page contract and design-system assets.

Do not create page-local visual systems. Missing product or design inputs must be recorded as assumptions or blockers before implementation is marked production ready.

When creating, updating, or proposing Codex automations, recurring tasks, reminders, monitors, or scheduled tasks, write the task name, description, prompt summary, status note, and user-facing explanation in Chinese by default. Use English only when the user explicitly asks for English.
