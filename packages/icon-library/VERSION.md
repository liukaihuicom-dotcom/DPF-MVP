# @dpf/icon-library Version

Current version: `4.1.8`

This package owns semantic icon registry, local icon assets, icon runtime contract, naming, source policy, and icon QA.

## Version Rules

| Segment | Meaning |
|---|---|
| Major | Breaking icon key, source policy, runtime contract, or migration alias change |
| Minor | New icon, category, renderer capability, or source-policy capability |
| Patch | Non-breaking glyph adjustment, metadata correction, QA, or documentation fix |

Every commit that changes this package must update `package.json` and `CHANGELOG.md`.
