# @dpf/component-library Version

Current version: `2.2.0`

This package owns reusable foundation, layout, form, feedback, data-display, and navigation component governance.

## Version Rules

| Segment | Meaning |
|---|---|
| Major | Breaking prop, state, slot, token-binding, or accessibility contract change |
| Minor | New governed component, variant, state, or slot |
| Patch | Documentation, manifest, QA, or non-breaking implementation correction |

Every commit that changes this package must update `package.json` and `CHANGELOG.md`.
