# @dpf/design-tokens Version

Current version: `3.4.0`

This package owns design tokens, token schemas, theme modes, runtime token exports, CSS variable mapping, and Tailwind mapping.

## Version Rules

| Segment | Meaning |
|---|---|
| Major | Breaking token semantic removal, rename, layer change, or cross-platform meaning change |
| Minor | New token family, semantic token, mode, mapping, or runtime export |
| Patch | Non-breaking value adjustment, documentation update, or QA rule fix |

Every commit that changes this package must update `package.json` and `CHANGELOG.md`.
